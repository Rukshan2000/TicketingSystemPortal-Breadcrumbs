# Customizing Report Letterhead

This guide explains how to customize the report letterhead to match your organization's branding.

## Quick Customization

### 1. Change Organization Details

Edit `src/components/reports/report-letterhead.tsx`:

```tsx
// Change these values:
<h1 className="text-3xl font-bold text-gray-900">Support Ticket System</h1>
// To your organization name:
<h1 className="text-3xl font-bold text-gray-900">Your Company Name</h1>

// Change description
<p className="text-sm text-gray-700 mt-1">Enterprise Support Management Platform</p>
// To:
<p className="text-sm text-gray-700 mt-1">Your Department or Description</p>

// Change contact info
<span>📧 support@organization.com</span>
<span>📞 1-800-SUPPORT</span>
<span>🌐 www.organization.com</span>
// To your actual contact details
```

### 2. Add Logo/Image

To add an organization logo:

```tsx
import Image from 'next/image';

// Add this in the letterhead header:
<div className="flex justify-center mb-4">
  <Image 
    src="/images/logo.png" 
    alt="Organization Logo"
    width={100}
    height={100}
  />
</div>
```

Place your logo image in `public/images/logo.png`

### 3. Modify Colors (For Screen Display Only)

The print version will always be black and white, but you can customize screen colors:

```tsx
// In the ReportLetterhead component:
<div className="w-full bg-white text-black border-b-2 border-slate-800">
  {/* Change border-slate-800 to your color, e.g., border-blue-800 */}
</div>

// Change text colors:
<h1 className="text-3xl font-bold text-gray-900">
  {/* Change text-gray-900 to your color */}
</h1>
```

### 4. Change Report Metadata

The letterhead automatically shows:
- Report Type (passed as `title` prop)
- Generated Date (auto-calculated or pass `generatedDate`)
- Generated By (passed as `generatedBy` prop)

Example usage:
```tsx
<ReportLetterhead
  title="Monthly Ticket Summary"
  generatedDate="January 8, 2026"
  generatedBy="John Doe, Support Manager"
/>
```

## Advanced Customization

### Modify Footer Disclaimer

In `src/components/reports/report-letterhead.tsx`:

```tsx
<div className="mt-4 pt-4 border-t border-gray-300 text-xs text-gray-600">
  <p>
    Change this text to your organization's disclaimer or legal notice.
  </p>
</div>
```

### Customize Contact Information Display

Replace the emoji-based contact info with styled sections:

```tsx
<div className="flex justify-center gap-6 mt-3 text-xs text-gray-600">
  <div className="text-center">
    <p className="font-semibold">Email</p>
    <p>support@organization.com</p>
  </div>
  <div className="text-center">
    <p className="font-semibold">Phone</p>
    <p>1-800-SUPPORT</p>
  </div>
  <div className="text-center">
    <p className="font-semibold">Website</p>
    <p>www.organization.com</p>
  </div>
</div>
```

### Add Department/Division Headers

```tsx
<div className="text-center mb-6 border-b border-gray-400 pb-4">
  <h1 className="text-3xl font-bold text-gray-900">Your Organization</h1>
  <h2 className="text-xl font-semibold text-gray-700">Department Name</h2>
  <h3 className="text-sm text-gray-600">Division or Section</h3>
  {/* Rest of letterhead */}
</div>
```

## Creating Report Templates

You can create multiple letterhead variations:

```tsx
// src/components/reports/report-letterhead-variants.tsx

export const ExecutiveLetterhead: React.FC<Props> = (props) => (
  <div className="w-full bg-white text-black border-b-4 border-gray-900 p-12">
    {/* Executive style */}
  </div>
);

export const SimpleLetterhead: React.FC<Props> = (props) => (
  <div className="w-full bg-white text-black border-b border-gray-400 p-4">
    {/* Simple style */}
  </div>
);

export const DetailedLetterhead: React.FC<Props> = (props) => (
  <div className="w-full bg-white text-black border-b-2 border-gray-800 p-8">
    {/* Detailed style with more information */}
  </div>
);
```

Then use in reports:
```tsx
import { SimpleLetterhead } from '@/components/reports/report-letterhead-variants';

<SimpleLetterhead title="Quick Report" />
```

## Dynamic Letterhead Based on Report Type

```tsx
const getLetterheadContent = (reportType: string) => {
  switch (reportType) {
    case 'tickets':
      return {
        title: 'Ticket Analysis Report',
        subtitle: 'Support Ticket Management',
      };
    case 'users':
      return {
        title: 'User Activity Report',
        subtitle: 'User Management & Analytics',
      };
    default:
      return {
        title: 'System Report',
        subtitle: 'Support Ticket System',
      };
  }
};
```

## Including Report Metadata

To include more information in the letterhead:

```tsx
interface ReportMetadata {
  reportType: string;
  dateRange: { start: string; end: string };
  totalRecords: number;
  filters: string[];
}

export const EnhancedLetterhead: React.FC<ReportMetadata> = ({
  reportType,
  dateRange,
  totalRecords,
  filters,
}) => (
  <div>
    {/* Standard letterhead */}
    
    {/* Additional metadata */}
    <div className="mt-4 grid grid-cols-3 gap-4 text-sm">
      <div>
        <p className="font-bold">Date Range</p>
        <p>{dateRange.start} to {dateRange.end}</p>
      </div>
      <div>
        <p className="font-bold">Total Records</p>
        <p>{totalRecords}</p>
      </div>
      <div>
        <p className="font-bold">Applied Filters</p>
        <p>{filters.length > 0 ? filters.join(', ') : 'None'}</p>
      </div>
    </div>
  </div>
);
```

## Responsive Design

The letterhead is responsive. For mobile/print, ensure proper scaling:

```tsx
<div className="w-full max-w-4xl mx-auto bg-white text-black border-b-2 border-gray-800 p-8">
  {/* Content automatically scales */}
</div>
```
